# MyDashboard
https://ghaziomairi93.github.io/MyDashboard/

Personal dashboard with Outlook inbox, Google Calendar and Reminders. Built with HTML, CSS and JavaScript using Microsoft Graph API.

BIG MINDS DASHBOARD
Version: 2.1.9

FEATURES:
- Live Weather (Open-Meteo API)
- Countdown (Local persistence)
- Tasks (LocalStorage)
- Google Calendar (Sync/Deep links)
- Outlook (PKCE Auth flow)

DEVELOPER NOTES:
- ‼️ Use the "Nuke" button to clear local storage if sessions desync.
- No external libraries used for OAuth to maximize Safari mobile compatibility.
