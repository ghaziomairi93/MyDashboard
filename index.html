📚 User Guide

📍 Location Powers all widgets

  • One location drives weather, clock, greeting, prayer times, calendar timezone, and background theme
  • Tap Set Location in greeting or Change Location in Prayer Times

⏱ LED Clock

  • Green seven-segment LED display synced to your location timezone
  • Background theme changes with time-of-day and weather condition

💰 Crypto Live

  • BTC, ETH, SOL, HNT via CoinGecko — auto-refresh every 5 min
  • Green = up, Red = down vs 24h ago

💲 Forex & Metals

  • USD/EUR, Gold and Silver per troy oz — auto-refresh every 5 min

☀️ Prayer Times

  • Fajr, Dhuhr, Asr, Maghrib, Isha via Aladhan API
  • Next prayer highlighted in teal — requires location

📰 Headlines

  • Top 5 NYT headlines — tap to open full article

📅 Mini Calendar

  • Tap any day to sync Reminders and Google Calendar
  • Arrows navigate months — today purple, selected cyan

⏳ Countdown

  • Set a name, date and optional time — tap Add Event
  • Under 24h: live HH:MM:SS ticker. Over 24h: Days and Hours
  • Tap Change Event to edit at any time

🔔 Reminders

  • Date/time picker sets due time — tap + to add task
  • Checkbox marks done, trash icon deletes permanently
  • Clear Done removes all completed tasks

📅 Google Calendar

  • Sign In with Google — Add creates real events in your calendar
  • Tap any event to open it in the Google Calendar app
  • Trash icon deletes from Google Calendar server

✉ Outlook

  • Microsoft PKCE login — 15 most recent unread emails
  • Tap any email to open in your mail app

🗑 Clear My Data

  • Wipes all tasks, location, countdown, sessions and tokens
